# CLAUDE.md — Telegram Mini App «Заметки»

Положите этот файл в корень нового репозитория. Claude Code читает его в начале каждой сессии.

## О проекте
Telegram Mini App для заметок с блочным редактором (BlockNote).
Полные требования — в `PRD.md`. Перед любой задачей сверяйся с ним.
Владелец проекта — не программист: объясняй решения простым языком, по-русски.

## Стек
React 18 + Vite + TypeScript (strict), Tailwind, BlockNote, TanStack Query,
Hono в Vercel Functions (`api/`), Supabase Postgres (только с сервера),
zod, Vitest, Playwright.

## Команды
- `npm run dev` — фронтенд + API локально
- `npm run typecheck` / `npm run lint` / `npm test` — должны быть зелёными перед коммитом
- `npm run build` — прод-сборка

## Правила
- Работай по одному этапу из `PRD.md` за раз. Сначала короткий план, потом код.
- После этапа: обнови раздел «Статус» ниже, запусти проверки, сделай коммит.
- Секреты — только из `process.env` на сервере. Никогда не клади токены в код,
  в `VITE_*` переменные или в коммиты. Новые переменные — сразу в `.env.example`.
- Браузер не ходит в Supabase напрямую. Все данные — через `/api/*`.
- Каждый запрос к БД фильтруется по `user_id` из проверенного initData.
- initData проверяется только через `@telegram-apps/init-data-node`.
- Изменения схемы БД — новым файлом в `supabase/migrations/NNNN_name.sql`;
  скажи владельцу, что его нужно выполнить в Supabase → SQL Editor.
- Все тексты интерфейса — в `src/i18n/ru.ts`.
- Цвета — только CSS-переменные темы Telegram (`--tg-*`), без захардкоженных hex.
- Mobile-first: проверяй вёрстку на ширине 375 px.
- Не добавляй функции из раздела «Вне MVP» без запроса.
